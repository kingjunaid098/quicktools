Git Commands Cheat Sheet

Useful Git commands with quick copy buttons

Git Command Use Case Copy
git init Initialize a new Git repository
git clone URL Clone an existing GitHub repository
git status Check current repository status
git add . Add all changed files to staging
git commit -m "message" Create a commit with message
git push origin main Push code to GitHub main branch
git pull origin main Fetch latest updates from GitHub
git remote -v View connected remote repositories
git branch See all local branches
git checkout branch-name Switch to another branch
git remote set-url origin URL Change connected GitHub repository
Remove-Item -Recurse -Force .git Remove Git tracking completely
